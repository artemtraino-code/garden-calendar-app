# Garden Calendar App

Отдельное веб-приложение для учета объектов огорода, будущих работ и журнала выполненных действий. Проект не связан с сайтом магазина и должен храниться отдельным репозиторием.

## Что уже есть

- дашборд с лентой всех будущих работ;
- отдельная вкладка объектов;
- добавление и настройка объектов;
- несколько работ ухода на один объект;
- отметка работы выполненной с пересчетом следующей даты от фактической даты;
- журнал выполненных работ;
- сохранение в `localStorage`;
- резервная копия текущих стартовых данных в `data/garden-calendar-state-2026-05-18.json`.

```powershell
cd C:\Users\artem\OneDrive\Документы\seeds\garden-calendar-app

```

После запуска открыть:

```text
http://localhost:5177/
```

## Текущие ограничения

- данные хранятся только в браузере на текущем устройстве;
- синхронизации между телефоном и компьютером пока нет;
- напоминаний через Telegram, push или Google Calendar пока нет;
- полноценный экспорт/импорт JSON еще нужно добавить в интерфейс.
